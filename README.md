# KKS कहानियाँ — मॉड्यूलर स्टोरी प्लेटफॉर्म और साझा वेब टेम्पलेट

यह प्रोजेक्ट **KKS कहानियाँ** (`https://manishmanwala.github.io/KKS-Kahaniyan/`) और साझा मॉड्यूलर वेब आर्किटेक्चर के लिए तैयार किया जा रहा है। इसमें **Firebase Firestore**, **Firebase Authentication**, और **GitHub Pages** का उपयोग किया गया है।

## मुख्य सिद्धांत
1. **हल्का `index.html`:** मुख्य प्रवेश द्वार केवल कंटेनर (`#app-root`) और `auto-loader.js` को संभालता है।
2. **सेंटर / रूट की फ़ाइलें:**
   - `index.html` — मुख्य ढांचा और एंट्री पॉइंट
   - `auto-loader.js` — `MODULES` सूची के आधार पर फ़ोल्डर/मॉड्यूल लोड करने वाला कंडक्टर
   - `app-state.js` — एक जगह से मुख्य नियंत्रण (`SITE_CONTROLS`) और बिना कोड बदले सेटिंग्स (`localStorage`) संभालने वाला केंद्र
   - `router.js` — व्यू/सेक्शन बदलने का सिस्टम
   - `styles.css` — साझा रंग, फ़ॉन्ट और बुनियादी लेआउट स्टाइल
   - `package.json` — प्रोजेक्ट की पहचान और जानकारी
   - `.gitignore` — निजी/अस्थायी/लोकल फ़ाइलों को बाहर रखने का नियम
   - `README.md` — प्रोजेक्ट का दस्तावेज़ और नक्शा
3. **मॉड्यूलर फ़ोल्डर्स (`01-...`, `02-...`, `10-...`, आदि):**
   - `01-core-config/` — `config.js` और `firebase-init.js`
   - आगे के फ़ीचर/कम्युनिटी मॉड्यूल क्रमानुसार अपने-अपने फ़ोल्डरों में बनाए जाते हैं।
4. **सुरक्षा और डेटा:**
   - डेटा की सुरक्षा **Firestore Security Rules** और **Firebase Authentication** से सुनिश्चित की जाती है।

## सेटिंग्स और नियंत्रण
- कोड स्तर के मुख्य नियंत्रण `app-state.js` में `SITE_CONTROLS` के अंतर्गत रखे गए हैं।
- ऐप की सेटिंग से किए गए बदलाव `updateAppSetting` / `resetAppSettings` के माध्यम से ब्राउज़र में सहेजे जाते हैं।
